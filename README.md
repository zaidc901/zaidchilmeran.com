# Zaid Chilmeran Portfolio

A responsive personal portfolio for Zaid Chilmeran, featuring medical research,
certifications, educational resources and an interactive venture profit simulator.

## Development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

The site uses React, Vite, React Router, Framer Motion and Recharts. Routes are
lazy-loaded so the charting code is only downloaded when the simulator opens.
